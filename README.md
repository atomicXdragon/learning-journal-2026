# My Learning Journal

## 27 10 2026

From the beginning, I decided on a Pinball Machine Game to design and develop since it was both made of fairly understandable components, and was conceptually something I was really interested in personally.

Work began on the Paddle (Flipper) component first (Unity project created.) I plan on working on the Paddles, Bumper/Kicker/Slingshot, Plunger and Point Tracker components next in no particular order.

## 24 11 2026

After being delayed significantly by various obligations and illness, I'm properly beginning work on my project. For the first component, since I require the background and a ball to work alongside/test with, I will package them alongside the Pinball component. I will be following this specific "Pinball" tutorial for Unity (https://youtu.be/0gzakhQgptI) for the most part, before splitting apart from it as I have to design the project as multiple "component" projects.

I began with spawning some primitives to make the wall behind the paddles, as well as the floor below the machine. When creating the ball, I applied a rigidbody component for physics, and increased the overall gravity in the project for more accurate ball movement.
